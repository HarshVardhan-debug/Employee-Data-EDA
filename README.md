# Employee Data Analysis (EDA)

A complete Exploratory Data Analysis (EDA) project performed on an Employee dataset using Python and popular data analysis libraries. This project focuses on understanding employee trends, salary distribution, department-wise analysis, missing value handling, and visual insights.

---

## 📌 Project Overview

This notebook performs:

* Data Cleaning
* Missing Value Treatment
* Data Transformation
* Statistical Analysis
* Visualization of Employee Trends
* Correlation Analysis
* Feature Understanding

The goal of this project is to extract meaningful insights from employee-related data and improve analytical understanding using Python.

---

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn

## 🚀 How to Run the Project

1. Clone the repository

```bash
git clone https://github.com/your-username/employee-eda.git
```

2. Navigate to the project folder

```bash
cd employee-eda
```

3. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn
```

4. Open Jupyter Notebook

```bash
jupyter notebook
```

5. Run the notebook file
